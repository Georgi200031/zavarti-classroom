# Завърти! — защитена класна стая

Цветна рулетка на български с учителски вход, равен шанс за всяко име, фойерверки, звук и режим без повторения.

Кодът е публичен. **Ученически имена, пароли и тайни не се съхраняват в това хранилище.** Имената се зареждат от сървър само след проверен вход. Публичната начална страница съдържа единствено формата за вход.

## Безплатен хостинг

Проектът е подготвен за **Cloudflare Workers Free**, без платени добавки, външна база данни или задължителен собствен домейн. Проверени условия на 2 ноември 2026 г.: до 100 000 Worker заявки дневно, споделени за акаунта, с други ограничения за ресурси. При превишаване сайтът може да спре да отговаря. Безплатният план е подходящ за малка класна стая, но не обещава неограничено ползване.

- [Официални лимити](https://developers.cloudflare.com/workers/platform/limits/)
- [Официални цени](https://developers.cloudflare.com/workers/platform/pricing/)
- [Rate limiting](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/)
- [Тайни на Worker](https://developers.cloudflare.com/workers/configuration/secrets/)

GitHub Pages не изпълнява защитения сървър и не е целевият хостинг. Не премествайте имената в `public/`.

## Локално стартиране

Необходим е Node.js 22 или по-нов. Локалният сървър и тестовете не изискват npm зависимости.

1. Изтеглете проекта и създайте папка `.private`.
2. Запишете UTF-8 файла `.private/roster.json` като масив от имена, например:

```json
["Пример Първи", "Пример Втори"]
```

3. Изпълнете:

```sh
npm run setup
npm test
npm run check
npm start
```

4. Отворете `http://127.0.0.1:8770`.
5. Данните за учителския вход са в `.private/teacher-login.txt`. Паролата се генерира локално и не се отпечатва в логове.

Папката `.private` е изключена чрез `.gitignore`. Не я качвайте ръчно през уеб интерфейса на GitHub — `.gitignore` не защитава от ръчно качване!

## Публикуване в Cloudflare

Необходим е ваш Cloudflare акаунт. Създаването на акаунт, приемането на условията и разрешаването на достъп до акаунта се извършват от собственика. Изберете безплатния план.

```sh
npm install
npx wrangler login
npm run deploy
npm run publish-secrets
```

`deploy` публикува Worker и статичните файлове. Докато тайните не са зададени, API отказва достъп. `publish-secrets` подава локалните стойности на Cloudflare през stdin, без да ги записва в кода или аргументите на процеса. Cloudflare съхранява тайните отделно от GitHub.

Конзолата на Wrangler връща действителния `https://…workers.dev` адрес. Не споделяйте учителската парола с учениците. Не включвайте платен план или платен домейн, ако желаете безплатно ползване.

Алтернатива за автоматични обновявания: свържете това GitHub хранилище през Cloudflare Workers Builds; deployment командата е `npx wrangler deploy`. Тайните се добавят отделно, никога в build настройките като публични стойности.

## Данни за вход и сигурност

- Един учителски акаунт с генерирана силна парола.
- PBKDF2-SHA-512 с индивидуална сол в браузъра; сървърът пази и сравнява само допълнително хеширан SHA-256 verifier. Паролата не се изпраща в отворен вид. Това избягва скъп KDF в ограниченото CPU време на Workers Free. Изпращаното доказателство е чувствително като парола и се защитава с HTTPS.
- Подписана двучасова сесия в `HttpOnly`, `Secure`, `SameSite=Strict` cookie при HTTPS.
- Ограничение до 8 опита за вход на адрес за минута, според регионалните броячи на Cloudflare.
- Проверка на Origin за заявките за вход и изход.
- Списъкът и сесиите не се кешират; частни файлове не се сервират.
- Имена и история не се пазят в `localStorage`. След изход се изчистват от страницата.
- Изходът изтрива cookie в текущия браузър. Вече копиран токен остава валиден до изтичане или смяна на ключа. За незабавно прекратяване на всички сесии завъртете тайните.
- Локалният HTTP режим използва отделна dev cookie; продукцията трябва да се отваря само през HTTPS.

За смяна на паролата и прекратяване на всички предишни сесии:

```sh
npm run setup -- --rotate
npm run publish-secrets
```

Редакторът на имената променя текущата сесия в браузъра. За постоянна промяна обновете `.private/roster.json` и изпълнете `setup -- --rotate`, след това `publish-secrets`. Това сменя и паролата. Генерираният нов вход е в локалния файл.

## Управление на колелото

- Натиснете „Завърти колелото“ или Space.
- Изключвайте отсъстващи чрез списъка.
- „Без повторения“ изважда избраните от следващото теглене.
- „Нов кръг“ изчиства историята и връща избраните, като пази отсъстващите.
- Има 3 продължителности, звук с изключване и цял екран.
- Поддържат се телефон, клавиатура и предпочитание за намалено движение.

## Структура

```text
public/             публичният интерфейс, без частни имена
server/worker.mjs   вход, сесия, защита и API за списъка
scripts/            локална настройка и публикуване на тайни
test/               проверки на достъпа и защитата
.private/           само локално; никога в GitHub
wrangler.jsonc      конфигурация за Cloudflare Workers
```
